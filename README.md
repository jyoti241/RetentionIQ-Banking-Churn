# RetentionIQ – Banking Customer Churn Prediction

##  Project Overview

RetentionIQ is a Machine Learning-based banking customer churn prediction system designed to identify customers who are likely to leave a bank. The system analyzes customer demographics, account information, transaction behavior, and banking activities to predict churn probability and help financial institutions take proactive retention measures.

This project demonstrates the practical implementation of Data Science, Machine Learning, Data Analysis, Feature Engineering, Predictive Modeling, and Business Intelligence while solving a real-world banking customer retention problem.

##  Installation & Setup

### Prerequisites

Before running the project, ensure you have:

* Python 3.8 or above
* Jupyter Notebook (Optional)
* VS Code / PyCharm
* Git (Optional)

### Clone the Repository

git clone https://github.com/jyoti241/RetentionIQ-Banking-Churn

### Open the Project

1. Open VS Code or PyCharm.
2. Select **Open Folder**.
3. Navigate to the RetentionIQ-Banking-Churn folder.
4. Open the project.

### Install Dependencies

pip install -r requirements.txt


### Run the Application

If using Streamlit:

streamlit run app.py

Or:

python app.py
