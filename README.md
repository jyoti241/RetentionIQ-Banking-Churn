# RetentionIQ-Banking-Churn
Machine learning project for predicting customer churn in banking and improving customer retention.
AI-powered Banking Churn Prediction System

## Problem Statement
Predict customers likely to churn in a banking environment.

## Dataset Features
- CreditScore
- Geography
- Gender
- Age
- Balance
- Tenure
- NumOfProducts
- etc.

## Models Used
- Logistic Regression
- Random Forest
- Decision Tree

## Libraries
- pandas
- numpy
- sklearn
- matplotlib
- seaborn

## Steps to Run
1. Install libraries
2. Open notebook
3. Run all cells

## Output
- Churn predictions
- Graphical insights
- Retention recommendations
